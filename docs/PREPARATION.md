# 整理说明

本目录以 `Tree_gnn_smalltest_2.py` 为主入口独立整理。未移动或修改原目录文件，目标 GitHub 仓库为 `marshmallow911/TDTW-GNN`。

## 收录范围

递归追踪主程序本地导入，收录主程序、`Tree_final_time_mptt.py`、`flow.py`、两份数据加载器、消息函数/聚合模块和本地评估器。`AML_data_loader.py` 虽不在默认 Ethereum 执行路径中，但仍被入口直接导入，因此一并保留。没有收录其他实验入口、基线、历史输出或模型权重。

为降低论文实现变化风险，保留原始模块名称和内部实现，没有拆分模型类或删除模块内的其他方法。

## 仅在副本中的修改

- 新增 `runtime_config.py`，替换原先解析后未用于超参数设置的 TGB 参数解析。随机种子函数仍使用原来的 TGB 实现。
- 将原有实验超参数接入 CLI，默认值保持原样。
- 移除程序内硬编码的 GPU 可见列表；设备改为自动选择或 `--device` 指定。复用原 GPU 索引可传 `--device cuda:2`。
- Ethereum 加载器的硬编码机器路径改为本目录下的 `data/subgraph.pkl`；默认训练函数新增 `graph_path` 参数，入口通过 `--data-path` 传入。
- 检查点写入本目录 `outputs/`，支持 `--output-dir`。
- 新增包初始化文件、README、数据格式说明、精简依赖清单和 Git 忽略规则，保留原 LICENSE。

训练/测试函数、模型、采样器、损失、数据处理运算和评估口径未改变。没有对原有指标选择或实验方法作纠正性修改。

## 检查及限制

整理时检查 Python 语法、本地导入闭包、CLI 帮助及非法参数，并比对未修改模块和训练/测试函数与原文件的一致性。源文件整理前的 SHA-256 见 `source_manifest.json`。
